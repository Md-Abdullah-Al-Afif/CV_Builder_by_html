# 🧾 Professional CV Builder

A fully interactive, browser-based CV/Resume builder with live preview and PDF export functionality. This tool allows users to create clean, professional, and customizable resumes instantly — no backend required.

---

## 🚀 Features

* ⚡ **Live Preview** – See your CV update in real-time while typing
* 🧩 **Modular Sections** – Add, remove, or reorder sections easily
* 👁️ **Toggle Visibility** – Show/hide sections dynamically
* 🏷️ **Tag-based Skills Input** – Add skills using smart tag inputs
* 📄 **PDF Export** – Download your CV as a high-quality PDF
* 🖨️ **Print Ready Layout** – Optimized for A4 printing
* 💾 **Local Storage Support** – Automatically saves your data in the browser
* 🎨 **Clean & Professional Design** – Elegant typography and layout
* ➕ **Custom Sections** – Add your own sections (e.g., Publications, Awards)

---

## 🛠️ Tech Stack

* **HTML5**
* **CSS3 (Custom Styling + Responsive Design)**
* **Vanilla JavaScript**
* **html2pdf.js** (for PDF export)

---

## 📸 Preview

> Live preview panel with real-time updates and zoom functionality.

---

## 🧠 How It Works

* All data is stored in **localStorage**
* The form dynamically updates a structured JSON object
* The CV preview is rendered from that JSON in real-time
* PDF export uses **html2pdf.js**

---

## 🧪 Usage

1. Fill in your personal information
2. Add education, experience, skills, and projects
3. Customize section order and visibility
4. Preview your CV live
5. Download as PDF or print

---

## 🔧 Customization

You can easily:

* Modify styles in the `<style>` section
* Add new sections in the JavaScript data structure
* Change fonts or layout
